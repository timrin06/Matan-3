Измеримые множества
и продолжение меры

Внешняя мера умеет оценивать любое множество сверху, но не обязана быть аддитивной. Найдём множества, для которых разрезание не теряет размер.

01 / ИСХОДНОЕ ПОЛУКОЛЬЦО

Внешняя мера не меняет исходную

Пусть \(\mu\) счётно аддитивна на полукольце \(\mathcal P\), а \(\mu^*\) построена по покрытиям. Тогда для любого \(A\in\mathcal P\)

\[\mu^*(A)=\mu(A).\]

Одно неравенство следует из покрытия самим \(A\). Для обратного сначала заменяем произвольное счётное покрытие \(A_i\) попарно непересекающимся. Последовательно вычитаем из \(A_i\) предыдущие множества. Разность может не лежать в полукольце, но распадается на конечное число непересекающихся его элементов. При этом суммарная мера новых кусков не больше суммарной меры покрытия.

Пересечём полученные непересекающиеся куски \(D_j\) с \(A\). Тогда \(A\cap D_j\in\mathcal P\), они не пересекаются и их объединение равно \(A\). Счётная аддитивность и монотонность дают \(\mu(A)=\sum_j\mu(A\cap D_j)\le\sum_j\mu(D_j)\). Переход к инфимуму по покрытиям завершает доказательство.

02 / КРИТЕРИЙ

Что значит «хорошо разрезает»

Лектор называет предмерой в этой части функцию \(\gamma:2^X\to[0,\infty]\), которая равна нулю на пустом множестве, монотонна и счётно полуаддитивна. Внешняя мера — пример такой функции. Термин здесь используется именно в смысле лекции.

ОПРЕДЕЛЕНИЕ

Множество \(E\subseteq X\) называется \(\gamma\)-измеримым, если для каждого \(T\subseteq X\)

\[\gamma(T)=\gamma(T\cap E)+\gamma(T\setminus E).\]

Полуаддитивность всегда даёт сторону \(\le\), потому что две части покрывают \(T\). Содержательная часть условия — обратное неравенство: разделение множества границей \(E\) не заставляет сумму размеров вырасти. Условие требуется для всех \(T\), а не только для самого \(E\).

03 / ТЕОРЕМА

Из предмеры получается мера

ТЕОРЕМА КАРАТЕОДОРИ

Совокупность всех \(\gamma\)-измеримых множеств образует сигма-алгебру, а ограничение \(\gamma\) на неё счётно аддитивно. Если \(\gamma=\mu^*\) построена по мере на полукольце, каждый элемент исходного полукольца \(\gamma\)-измерим. Если \(\mu\) счётно аддитивна, ограничение \(\mu^*\) является её продолжением.

Полученная сигма-алгебра может быть шире сигма-алгебры, порождённой полукольцом. В частности, при построении меры Лебега она содержит борелевские множества и все подмножества множеств нулевой меры.

04 / СХЕМА ДОКАЗАТЕЛЬСТВА

От двух разрезов к счётному числу

Пустое множество измеримо; определение симметрично относительно \(E\) и \(E^c\), поэтому дополнение измеримого множества измеримо.

Для двух измеримых множеств последовательно разрезаем произвольное \(T\) сначала по \(E_1\), а затем часть \(T\cap E_1\) по \(E_2\). Получаются три части: внутри \(E_1\cap E_2\), внутри \(E_1\setminus E_2\) и вне \(E_1\). Последние две вместе образуют \(T\setminus(E_1\cap E_2)\). Полуаддитивность позволяет оценить их сумму снизу мерой объединения, после чего получается обратная сторона условия измеримости пересечения. Значит, измеримые множества образуют алгебру.

Пусть теперь \(E_i\) измеримы и попарно не пересекаются. Последовательно разрезая \(T\), для каждого \(N\) получаем

\[\gamma(T)=\sum_{i=1}^N\gamma(T\cap E_i)+\gamma\!\left(T\setminus\bigcup_{i=1}^N E_i\right).\]

Остаток содержит \(T\setminus\bigcup_{i\ge1}E_i\). По монотонности можно заменить его соответствующим меньшим слагаемым и перейти к пределу по \(N\). Полуаддитивность оценивает сумму снизу через \(\gamma(T\cap\bigcup_iE_i)\). Так получается измеримость счётного объединения; произвольное объединение предварительно разбиваем на непересекающиеся измеримые части. Подстановка \(T=\bigcup_iE_i\) даёт счётную аддитивность.

Для исходного множества \(A\) полукольца любое покрытие произвольного \(T\) разрезаем по \(A\). Пересечения лежат в полукольце, а разности представляются конечными непересекающимися объединениями его элементов. Конечная аддитивность показывает, что суммарная стоимость обеих частей не превышает стоимости исходного покрытия. Инфимум по покрытиям даёт нужную обратную оценку в критерии измеримости.
