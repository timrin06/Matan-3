Сходимость по мере и приближение в \(L^p\)

Поточечная сходимость контролирует поведение в каждой точке; сходимость по мере контролирует размер множества точек с большим отклонением. Это позволяет перейти к приближению функций в норме.

01 / ОПРЕДЕЛЕНИЕ

Сходимость по мере

Измеримые функции \(f_n\) сходятся к измеримой функции \(f\) по мере, если для каждого \(\varepsilon>0\)

\[\mu\{x:|f_n(x)-f(x)|>\varepsilon\}\longrightarrow0.\]

Множество, на котором отклонение заметно, может перемещаться и даже не уменьшаться по включению: важно, что его мера стремится к нулю.

Если \(\mu(X)<\infty\), то сходимость почти всюду влечёт сходимость по мере. Действительно, для фиксированного \(\varepsilon\) множества \(A_N=\bigcup_{n\ge N}\{|f_n-f|>\varepsilon\}\) убывают к множеству меры ноль; по непрерывности меры сверху \(\mu(A_N)\to0\). Конечность меры здесь нужна. На \(\mathbb R\) функции \(\mathbf1_{[n,n+1]}\) сходятся к нулю в каждой точке, но не по мере.

01a / СРАВНЕНИЕ

Какие сходимости связаны

Три вида сходимости отвечают на разные вопросы: почти всюду — что происходит в отдельных точках, по мере — насколько велико множество ошибок, в \(L^p\) — каков интеграл степени ошибки.

ОСНОВНЫЕ СВЯЗИ

\(L^p\)-сходимость \(\Longrightarrow\) сходимость по мере: по Чебышёву

\[\mu\{|f_n-f|>\varepsilon\}\leq\varepsilon^{-p}\|f_n-f\|_p^p.\]

Сходимость почти всюду \(\Longrightarrow\) сходимость по мере при \(\mu(X)<\infty\). Сходимость по мере \(\Longrightarrow\) сходимость почти всюду некоторой подпоследовательности.

Обратный переход от сходимости по мере к сходимости в \(L^p\) неверен даже на пространстве конечной меры. При \(1\leq p<\infty\) на \((0,1)\) положим \(f_n=n^{1/p}\mathbf1_{(0,1/n)}\). Тогда \(f_n\to0\) почти всюду и по мере, но \(\|f_n\|_p=1\) для каждого \(n\): растущая высота компенсирует уменьшение носителя.

Доказательство следствия о подпоследовательности — следующий раздел; примеры в этом блоке добавлены для сравнения определений.

02 / ПОДПОСЛЕДОВАТЕЛЬНОСТЬ

Из сходимости по мере — к сходимости почти всюду

ТЕОРЕМА

Если \(f_n\to f\) по мере, то существует подпоследовательность \(f_{n_k}\to f\) почти всюду.

Доказательство. Последовательно выбираем \(n_k\), чтобы \(n_k>n_{k-1}\) и

\[\mu(E_k)<2^{-k},\qquad E_k=\{|f_{n_k}-f|>2^{-k}\}.\]

Для \(B_m=\bigcup_{k\ge m}E_k\) имеем \(\mu(B_m)\leq\sum_{k\ge m}2^{-k}\to0\). Поэтому множество точек, принадлежащих бесконечно многим \(E_k\), имеет меру ноль. В каждой остальной точке начиная с некоторого номера \(|f_{n_k}-f|\leq2^{-k}\), что и доказывает сходимость.

Получить сходимость всей последовательности почти всюду вообще нельзя: например, последовательно перечислим характеристические функции двоичных интервалов \([j2^{-m},(j+1)2^{-m})\), \(j=0,\ldots,2^m-1\), при \(m=0,1,2,\ldots\). Их носители имеют меры, стремящиеся к нулю, но в каждой точке \([0,1)\) значения бесконечно часто равны и нулю, и единице.

03 / ПРЕДЕЛ ПОД ИНТЕГРАЛОМ

Теорема Лебега при сходимости по мере

ТЕОРЕМА

Пусть \(f_n,f\) измеримы, \(f_n\to f\) по мере и \(|f_n|\leq g\) почти всюду для всех \(n\), где \(g\geq0\) и \(g\in L^1\). Тогда \(f\in L^1\) и \(\int|f_n-f|\,d\mu\to0\).

Интуиция. На множестве малого отклонения разность мала; на множестве большого отклонения оно может быть велико, но интеграл мажоранты там мал благодаря абсолютной непрерывности интеграла.

Доказательство. Выделим подпоследовательность, сходящуюся почти всюду. Переходя к пределу в \(|f_{n_k}|\leq g\), получаем \(|f|\leq g\) почти всюду; следовательно, \(f\) суммируема.

Сначала пусть \(\mu(X)<\infty\). Для \(E_n=\{|f_n-f|>\varepsilon\}\) имеем

\[\int_X |f_n-f|\,d\mu\leq 2\int_{E_n}g\,d\mu+\varepsilon\mu(X).\]

При фиксированном \(\varepsilon\) первое слагаемое стремится к нулю, так как \(\mu(E_n)\to0\). Затем устремляем \(\varepsilon\) к нулю.

В общем случае положим \(B_m=\{g>1/m\}\). По неравенству Чебышёва \(\mu(B_m)<\infty\), а \(\int_{X\setminus B_m}g\to0\) по теореме о монотонной сходимости. На фиксированном \(B_m\) уже применим доказанный конечномерный по мере случай. Поэтому

\[\limsup_{n\to\infty}\int_X|f_n-f|\,d\mu\leq 2\int_{X\setminus B_m}g\,d\mu\longrightarrow0.\]

Отсюда также \(\int f_n\,d\mu\to\int f\,d\mu\).

04 / ПЛОТНОСТЬ

Приближение простыми функциями

ТЕОРЕМА

При \(1\leq p<\infty\) простые измеримые функции, принадлежащие \(L^p\), плотны в \(L^p\).

Доказательство. Для \(g\geq0\), \(g\in L^p\), выберем простые \(g_n\) так, что \(0\leq g_n\uparrow g\) почти всюду. Тогда \(|g-g_n|^p\to0\) почти всюду и \(|g-g_n|^p\leq g^p\in L^1\). По теореме Лебега \(\|g-g_n\|_p\to0\). Произвольную вещественную функцию представляем как \(f=f^+-f^-\) и приближаем обе части; для комплексной отдельно приближаем вещественную и мнимую части.

Каждую такую простую функцию можно записать как конечную сумму характеристических функций множеств конечной меры: если ненулевая ступенька имеет высоту \(c\), её носитель \(E\) удовлетворяет \(|c|^p\mu(E)<\infty\).

05 / ИСХОДНОЕ ПОЛУКОЛЬЦО

От простых функций к элементарным

Пусть мера построена продолжением меры с полукольца \(\mathcal B\). Элементарной здесь называется конечная линейная комбинация характеристических функций множеств из \(\mathcal B\); для принадлежности \(L^p\) берём множества конечной меры. Это название относится к исходному полукольцу, а не к элементарным функциям школьного курса.

ТЕОРЕМА

При \(1\leq p<\infty\) элементарные функции плотны в \(L^p\) относительно продолженной меры.

Доказательство. Достаточно приблизить индикатор измеримого множества конечной меры \(E\): после этого приближаем каждую ступеньку фиксированной простой функции и применяем неравенство треугольника.

По построению продолжения для любого \(\delta>0\) множество \(E\) можно покрыть счётным объединением \(A=\bigcup_{j\ge1}B_j\), \(B_j\in\mathcal B\), с \(\mu(A\setminus E)<\delta\) и \(\mu(A)<\infty\). Для конечных объединений \(A_N=\bigcup_{j=1}^N B_j\) имеем \(\mu(A\setminus A_N)\to0\). Поэтому при достаточно большом \(N\)

\[\mu(E\triangle A_N)\leq\mu(A\setminus E)+\mu(A\setminus A_N)<2\delta,\qquad \|\mathbf1_E-\mathbf1_{A_N}\|_p=\mu(E\triangle A_N)^{1/p}.\]

Конечное объединение множеств полукольца разбивается на конечное число непересекающихся множеств полукольца, поэтому \(\mathbf1_{A_N}\) — элементарная функция. Выбирая \(\delta\) сколь угодно малым, получаем нужное приближение.

Здесь использовано свойство внешнего приближения, установленное при продолжении меры. Для меры Лебега в \(\mathbb R^n\) исходными множествами служат подходящие прямоугольные параллелепипеды.
