Измеримая оболочка
и множества меры ноль

Внешняя мера определена даже для неизмеримого множества. При этом его можно накрыть измеримым множеством, не увеличив внешний размер. Это связывает конструкцию меры с вопросом о её единственности.

01 / ПРИБЛИЖЕНИЕ СНАРУЖИ

Оболочка той же внешней меры

Пусть \(\mu\) — счётно-аддитивная мера на полукольце \(\mathcal P\), а \(\mu^*\) — построенная по ней внешняя мера. Обозначим \(\mathcal A=\sigma(\mathcal P)\). Поскольку все элементы полукольца измеримы по Каратеодори, множества из \(\mathcal A\) также измеримы.

УТВЕРЖДЕНИЕ

Для любого \(E\subseteq X\) существует \(B\in\mathcal A\), для которого

\[E\subseteq B,\qquad \mu^*(E)=\mu^*(B).\]

Идея. Сначала пусть \(\mu^*(E)<\infty\). По определению инфимума для каждого \(n\) найдётся счётное покрытие \(E\) элементами полукольца, сумма мер которых меньше \(\mu^*(E)+2^{-n}\). Обозначим объединение этого покрытия через \(B_n\). Тогда \(B_n\in\mathcal A\), \(E\subseteq B_n\), и по полуаддитивности

\[\mu^*(E)\leqslant\mu^*(B_n)\leqslant\mu^*(E)+2^{-n}.\]

Теперь берём \(B=\bigcap_{n=1}^{\infty}B_n\). Это измеримое множество по-прежнему содержит \(E\), а монотонность зажимает его меру между \(\mu^*(E)\) и \(\mu^*(E)+2^{-n}\) при каждом \(n\). Если \(\mu^*(E)=\infty\), можно взять \(B=X\).

Порядок операций важен для представления оболочки: сначала в каждом покрытии берётся счётное объединение, затем — счётное пересечение полученных множеств. Именно этот переход лектор использует при обсуждении продолжений меры.

01a / СИГМА-МНОЖЕСТВА

Что именно образует оболочку

Лектор называет \(\sigma\)-множеством счётное объединение элементов исходного полукольца. Его можно переписать как счётное объединение попарно непересекающихся элементов полукольца: последовательно вычитаем ранее выбранные куски, а каждую разность разбиваем на конечное число допустимых множеств. Поэтому два продолжения исходной счётно-аддитивной меры совпадают на всех \(\sigma\)-множествах.

Для множества конечной внешней меры оболочку \(B\) выше можно построить как счётное пересечение \(\sigma\)-множеств \(B_n\). Этим и важна конструкция: любое другое продолжение совпадает с исходным на каждом \(B_n\), а после замены \(B_n\) конечными пересечениями и применения непрерывности меры сверху — и на \(B\). Здесь используется конечность меры хотя бы одного множества последовательности.

02 / НУЛЕВОЙ РАЗМЕР

Почему множество внешней меры ноль измеримо

Здесь достаточно любой внешней меры \(\gamma\) на \(X\), а не только построенной по полукольцу. Если \(\gamma(N)=0\), то по монотонности и \(\gamma(T\cap N)=0\) для любого \(T\subseteq X\). Поэтому

\[\gamma(T\cap N)+\gamma(T\setminus N)=\gamma(T\setminus N)\leqslant\gamma(T).\]

Обратное неравенство следует из полуаддитивности, так как две части объединяются в \(T\). Значит, выполнен критерий Каратеодори: каждое множество внешней меры ноль измеримо.

Здесь не предполагается заранее, что \(N\) измеримо: это и есть вывод. Более того, любое подмножество \(N\) имеет внешнюю меру ноль и, следовательно, тоже измеримо.

03 / ПОЛНОТА

Можно ли выбросить часть нулевого множества?

ОПРЕДЕЛЕНИЕ

Мера \(\nu\) на \(\mathcal F\) называется полной, если из \(N\in\mathcal F\), \(\nu(N)=0\) и \(A\subseteq N\) следует \(A\in\mathcal F\).

В силу монотонности такое \(A\) тоже имеет меру ноль. Ограничение внешней меры на всю сигма-алгебру множеств, измеримых по Каратеодори, полно: это непосредственно следует из предыдущего утверждения.

Важно различать эту полную сигма-алгебру и \(\sigma(\mathcal P)\): вторая может не содержать всех подмножеств своих нулевых множеств. Поэтому совпадение продолжений на порождённой сигма-алгебре само по себе ещё не означает, что их области определения одинаковы.

03a / ПРИМЕР ЛЕКТОРА

Нулевое не означает маленькое по мощности

Прямая на плоскости имеет двумерную меру Лебега ноль: она есть счётное объединение ограниченных отрезков, каждый из которых можно рассматривать как прямоугольник с нулевой второй стороной. Поэтому любое её подмножество измеримо по двумерной мере Лебега.

На самой числовой прямой ту же роль играет канторово множество: его мера ноль, но мощность равна континууму. Его подмножества дают \(2^{\mathfrak c}\) измеримых по Лебегу множеств, тогда как борелевских множеств только \(\mathfrak c\). Так полнота меры существенно расширяет борелевскую сигма-алгебру.

04 / ЗАЧЕМ НУЖНА СИГМА-КОНЕЧНОСТЬ

Единственность продолжения

ТЕОРЕМА

Пусть \(\mu\) — счётно-аддитивная мера на полукольце \(\mathcal P\), причём \(X\) можно покрыть счётным числом множеств \(P_n\in\mathcal P\) конечной меры. Тогда любые две счётно-аддитивные меры на \(\sigma(\mathcal P)\), продолжающие \(\mu\), совпадают.

Идея доказательства. В конечномерном по мере случае сначала сравниваем два продолжения на множествах полукольца: там они равны по условию. Свойства счётной аддитивности позволяют перенести равенство на сигма-алгебру, порождённую полукольцом. Именно конечность позволяет в необходимых разностях вычитать меры без неопределённости \(\infty-\infty\).

В общем случае разбиваем пространство на счётное семейство попарно непересекающихся измеримых множеств конечной меры: последовательно вычитаем из каждого \(P_n\) предыдущие. Сравниваем ограничения двух продолжений на каждом куске и складываем равенства по всем кускам.

Более подробный переход для множества конечной меры. Пусть два продолжения определены на сигма-алгебрах \(\mathcal B\) и \(\mathcal C\), и \(E\in\mathcal B\cap\mathcal C\) имеет конечную меру в стандартном продолжении \(\bar\mu\). Выберем содержащую \(E\) оболочку \(B\in\sigma(\mathcal P)\) той же меры. На \(B\) продолжения совпадают, так как оно построено из \(\sigma\)-множеств и непрерывности сверху. Разность \(B\setminus E\) имеет \(\bar\mu\)-меру ноль и лежит в обеих сигма-алгебрах. Она содержится в другом множестве из \(\sigma(\mathcal P)\) с нулевой \(\bar\mu\)-мерой; на этой оболочке вторая мера тоже равна нулю. Поэтому обе меры равны на \(B\setminus E\), а значит, и на \(E\). Далее \(\sigma\)-конечность позволяет разбить пространство на конечные по мере куски и сложить равенства.

Лектор также рассматривает сравнение на общей части областей определения: при конечной внешней мере множество можно зажать между измеримым множеством и оболочкой той же меры; оставшаяся разность имеет меру ноль. Чтобы сравнить её в другой мере, строится оболочка нулевой меры. Общий случай затем сводится к конечному с помощью \(\sigma\)-конечности.
